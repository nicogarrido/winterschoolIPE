# Escuela de Invierno — IPE UNAB

Sitio de descarga de material para las asignaturas de la **Escuela de Invierno**
del Instituto de Economía Política, Universidad Andrés Bello.

Cursos:
- **Microeconometría** → `material/microeconometria/`
- **Macroeconometría** → `material/macroeconometria/`

## Cómo funciona

`index.html` es una página estática que lista automáticamente los archivos
presentes en cada carpeta de curso (usando la API pública de GitHub). Para
publicar material, basta con subir archivos a la carpeta correspondiente: el
sitio los muestra con un botón de descarga, sin editar código.

## Publicación

Ver **[GUIA.md](GUIA.md)** para el paso a paso (crear repo, subir archivos y
activar GitHub Pages).

## Agregar un curso

Editar el bloque `COURSES` al inicio de `index.html` y crear la carpeta
correspondiente dentro de `material/`.
